# baserom: your own discs

Put an image of each disc you own here: an `.iso`, or the `.img`/`.bin` of a
raw CD dump (the prototype is one). Any file name works. Everything in this
directory except this file is ignored by git and is never committed or shared
([docs/policy/SOURCING.md](../docs/policy/SOURCING.md)).

```sh
python3 tools/openthievius.py discs           # which game and version each image is
python3 tools/openthievius.py discs --full    # and check every disc checksum below
python3 tools/openthievius.py setup           # put each game's inputs in its project
```

Images are recognised by the executable `SYSTEM.CNF` boots and that
executable's SHA-1, so file names do not matter. Other releases (Greatest
Hits, other regions) are reported as unknown, and the May 2002 prototype is
recognised and skipped ([docs/policy/SOURCING.md](../docs/policy/SOURCING.md#the-prototype)).
`setup` never overwrites a file that is already there.
