## What is OpenThievius?

OpenThievius brings *Sly Cooper and the Thievius Raccoonus* (Sucker Punch Productions, 2002) to PC as a real native game. No emulator.

- **How:** the game is decompiled into source that rebuilds the original executable exactly ([sly1-decomp](https://github.com/OpenThievius/sly1-decomp)), then built for your PC by the native port here.
- **Where it stands:** the port is not playable yet. `sly1-decomp` master `dd7a1860` matches all 4,807 US functions and 100% of code; 99.97% of data is matched. The latest host32 build compiles 194 Sly source units and 65 port-only backfills; its direct frame-call scan resolves 822/830 functions. These are build coverage figures, not proof of gameplay. Two port-only staging fixes now get native startup past the stream-reader ABI fault and the undersized `g_elementStack` buffer. Wave 48 ran over 3,100 frames without crashing and captured the correctly proportioned no-card warning page with Continue selected. No title or gameplay scene is confirmed. No card-format action was taken. See the [port roadmap](docs/port/ROADMAP.md) for current evidence and the next blocker.
- **No game files included:** models, textures, sound and levels come from your own disc.

## Get started

```sh
git clone https://github.com/OpenThievius/OpenThievius.git
git clone https://github.com/OpenThievius/sly1-decomp.git     # beside it
cd OpenThievius
python3 tools/openthievius.py discs ~/path/to/discs      # which discs you have
python3 tools/openthievius.py setup sly1 --discs ~/path/to/discs
```

`setup` puts each version's boot executable in sly1-decomp's `baserom/` and links its compiler from [toolchains/](toolchains/README.md). Then follow [sly1-decomp's README](https://github.com/OpenThievius/sly1-decomp#quick-start).
